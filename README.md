# tiliparser

tiliparser helps find recurring, easy-to-miss payments that leave your account every month.
Upload a bank CSV and the app surfaces likely recurring outflows.

All processing happens locally in your browser. No backend, no database.

Website: https://touho.kapsi.fi/tiliparser/

## Development
- `npm run dev` — start the dev server

## Adding new parsers
If your bank is missing, you can vibe a parser in `src/parsers/`.
